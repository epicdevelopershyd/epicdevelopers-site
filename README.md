# epicdevelopers.in — Epic Developers website

Static rebuild of the Epic Developers brochure site. No WordPress, no agency, no backend.

- Pages: home, Park Central, Villas at Park Central, The Greens, Eden Gardens (completed), Dream Acres (sold out), Contact.
- Images are mirrored from the old live site by `.github/workflows/fetch-assets.yml` into `assets/img/` (runs automatically on first push; re-run from the Actions tab if needed).
- Contact form opens a pre-filled WhatsApp message to +91 789 368 4545 — no server needed.
- Deployed on Render as a static site (`render.yaml`).
